# شعار مؤسسة النصر للمحاماة

شعار جديد متصمم من الأول: ميزان متناسق مرسوم يدويًا بالكود، والاسم مكتوب بخط رقعة (Aref Ruqaa) ومتحوّل لمسارات فيكتور، فمش محتاج أي خط يكون متسطّب.
افتح `preview.html` في المتصفح عشان تشوف الستة أنيميشن جنب بعض.

## الملفات

| الملف | الاستخدام |
|---|---|
| `logo.svg` | الشعار الذهبي (فيكتور) |
| `logo-white.svg` | أبيض — للخلفيات الغامقة |
| `logo-black.svg` | أسود — للطباعة والأختام |
| `png/` | نسخ PNG مقاس 2000×2000 بخلفية شفافة |
| `animations/` | الستة أنيميشن كملفات SVG — للموقع |
| `video/*.mp4` | كل أنيميشن كفيديو 1080×1080، 6 ثواني، خلفية بيضاء |
| `video/*-transparent.webm` | نفس الفيديوهات بخلفية شفافة |

## الستة أنيميشن

| # | الملف | الاسم | الفكرة |
|---|---|---|---|
| 1 | `anim-1-draw.svg` | رسم بالقلم | الحدود تترسم بخط ذهبي، وبعدين تتملي بالذهب، ولمعة في الآخر |
| 2 | `anim-2-balance.svg` | توازن الميزان | العمود يطلع، والذراع تنزل وتتأرجح لحد ما تتوازن، وبعدها الاسم |
| 3 | `anim-3-write.svg` | كتابة من اليمين | الكلمات تتكتب من اليمين للشمال، والزخرفة تتمد |
| 4 | `anim-4-shine.svg` | لمعة ذهبية | ظهور من ضباب ناعم، ولمعة ونجوم صغيرة بتلمع |
| 5 | `anim-5-assemble.svg` | تجميع القطع | كل جزء بييجي من اتجاه ويتركّب في مكانه |
| 6 | `anim-6-seal.svg` | الختم | الشعار ينزل زي الختم مع موجة، وحلقتين يترسموا حواليه |

## على الموقع

```html
<img src="brand/logo/animations/anim-2-balance.svg" alt="مؤسسة النصر للمحاماة" width="320">
```

كل أنيميشن بيشتغل مرة واحدة ويقف على الشعار كامل. وبيتوقف لوحده لو الزائر مفعّل «تقليل الحركة» على جهازه.

## الطبقات (IDs)

`title` (مؤسسة) · `stand` (عمود الميزان) · `arm` (الذراع والكرة) · `side-l` / `side-r` (الحبال والكفّتين) ·
`name` (النصر) · `sub` (للمحاماة) · `orn` (الزخرفة)

## التعديل وإعادة التوليد

السكربتات في `source/`:

1. `logo.py`: هندسة الميزان ومكان الكلام. غيّر المقاسات هنا.
2. `build.py`: الألوان والستة أنيميشن.
3. `render.js` + ffmpeg: تصدير الفيديوهات.
4. `gallery.py`: صفحة المعاينة.

```bash
pip install uharfbuzz fonttools
python3 source/logo.py parts.json && python3 source/build.py parts.json out/
```

خط Aref Ruqaa مرخّص بـ SIL Open Font License (موجود في `source/fonts/OFL.txt`) ومسموح استخدامه تجاريًا في الشعارات.
