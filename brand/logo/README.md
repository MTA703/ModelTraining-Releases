# شعار مؤسسة النصر للمحاماة

نسخة فيكتور (SVG) من الشعار، متقسّمة لطبقات جاهزة للأنيميشن.

| الملف | الاستخدام |
|---|---|
| `logo.svg` | الشعار الثابت (فيكتور، يكبر لأي مقاس من غير ما يبوظ) |
| `logo-animated.svg` | الشعار متحرك (CSS جوّه الملف) — للموقع |
| `logo-2000.png` | صورة PNG بخلفية شفافة 2000×2000 |
| `video/logo-animation-white.mp4` | فيديو 1080×1080، 7 ثواني، خلفية بيضاء |
| `video/logo-animation-transparent.mov` | فيديو بخلفية شفافة (QuickTime Animation) — لبرامج المونتاج (Premiere / After Effects / Final Cut) |
| `video/logo-animation-transparent.webm` | فيديو بخلفية شفافة (VP9) — للموقع |
| `preview.html` | صفحة معاينة فيها زرار إعادة تشغيل |

## الأنيميشن (حوالي 6 ثواني)

1. **0 – 2.7 ث:** رسم حدود الشعار بخط ذهبي (الميزان الأول، بعدين «النصر»، بعدين «مؤسسة» و«للمحاماة»).
2. **1 – 3.4 ث:** التعبئة بالتدرّج الذهبي.
3. **2.6 – 5.4 ث:** الميزان يتأرجح ويرجع يتوازن (الكفّتين بيفضلوا مستويين).
4. **4.6 – 6 ث:** لمعة ضوء بتعدّي على الشعار.

## على الموقع

```html
<!-- أبسط طريقة -->
<img src="brand/logo/logo-animated.svg" alt="مؤسسة النصر للمحاماة" width="300">
```

لو عايز تتحكم في الأنيميشن بـ JavaScript أو CSS، حط محتوى `logo-animated.svg` جوّه الـ HTML مباشرة (inline).
الأنيميشن بيتوقف تلقائيًا لو المستخدم مفعّل «تقليل الحركة» في جهازه.

## الطبقات (IDs)

`title` (مؤسسة) · `beam` (ذراع الميزان) · `hanger-left` / `hanger-right` (الحبال) ·
`pan-left` / `pan-right` (الكفّتين) · `name` (النصر + عمود الميزان) · `subtitle` (للمحاماة)

## إعادة التوليد

السكربتات في `source/`:
`trace.py` (تحويل الصورة لمسارات) ← `build.py` (بناء ملفات SVG) ← `render.js` (تصدير فريمات للفيديو بـ Playwright، وبعدها ffmpeg).
